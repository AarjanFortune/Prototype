📞 TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Backend won't start:
  → Activate venv: source backend/venv/bin/activate
  → Install deps: pip install -r requirements.txt
  → Try different port: --port 8001

Frontend won't load:
  → Clear cache: rm -rf node_modules package-lock.json
  → Reinstall: npm install
  → Check dev server: npm run dev

Port in use:
  → Find process: lsof -i :8000
  → Use different port: --port 8001

CORS errors:
  → Restart backend
  → Check CORS_ORIGINS in config.py

Microphone denied:
  → Check browser permissions
  → Try incognito mode
  → Allow in browser settings
